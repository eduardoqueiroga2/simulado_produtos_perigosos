# Simulado de Produtos Perigosos — publicação

Arquivos para a raiz do repositório GitHub Pages:
- `index.html` — simulado com 90 questões e comentários específicos por alternativa.
- `revisao-produtos-perigosos.pdf` — apresentação de revisão.
- `resumo-produtos-perigosos.pdf` — resumo de apoio.

Envie os três arquivos para a raiz do repositório. Mantenha os nomes exatamente como estão, pois os botões do HTML apontam para esses caminhos.

Os comentários foram escritos com base no resumo fornecido para o curso e incluem referências às páginas indicadas no banco de questões. Conteúdos normativos/operacionais devem ser conferidos com o instrutor e as referências oficiais vigentes.
