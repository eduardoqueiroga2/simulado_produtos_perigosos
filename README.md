# Simulado de Produtos Perigosos — publicação

Arquivos para a raiz do repositório GitHub Pages:
- `index.html` (site do simulado)
- `revisao-produtos-perigosos.pdf` (PDF principal de revisão; 79 páginas/slides)
- `resumo-produtos-perigosos.pdf` (resumo complementar)

Os comentários das alternativas priorizam a referência ao PDF de Revisão, indicando a página correspondente (equivalente ao número do slide da apresentação). Quando pertinente, também indicam a página do Resumo como fonte complementar.

No GitHub, substitua o `index.html` atual pelo HTML fornecido, renomeando-o para `index.html`, e mantenha os dois PDFs com os nomes exatos acima. O progresso do quiz é salvo localmente no navegador do usuário.
