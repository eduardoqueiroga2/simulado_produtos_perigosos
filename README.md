# Simulado de Produtos Perigosos

Site estático em HTML, CSS e JavaScript, pronto para GitHub Pages.

## Publicar
1. Crie um repositório no GitHub.
2. Envie `index.html` para a raiz do repositório.
3. Em **Settings → Pages**, escolha **Deploy from a branch**, selecione a branch principal e a pasta `/ (root)`.
4. Salve e aguarde a publicação.

As respostas são salvas no `localStorage` do navegador/dispositivo; não há envio de dados para servidor.

## Arquivos
- `index.html`: o único arquivo necessário para o funcionamento do site.
- `REVISAO-EDITORIAL.md`: relatório de apoio para quem mantém o projeto; opcional e não necessário para o site funcionar.

## Nota de conteúdo
O simulado mantém 90 questões, divididas em 30 fáceis, 30 médias e 30 difíceis. As posições do gabarito foram redistribuídas para evitar padrão previsível. As questões 39 e 90 foram reformuladas para corrigir a anotação de gabarito e evitar uma orientação operacional insegura. As demais questões ainda devem ser conferidas pelo instrutor contra a versão vigente das normas e o conteúdo ministrado; este site é material de estudo, não protocolo de atendimento.
